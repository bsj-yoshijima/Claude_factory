# スキン・パーツ定義の型（被り物 / 着るもの）

スキン = **今のマスコットに重ね着させる装備オーバーレイ**。1スキン = `head`(被り物) + `body`(着るもの) の1セット。
Stitchではなく**コードで重ね描き**する。ベースのマスコット（色付き）は常に残り、その上にこのオーバーレイを重ねる。
オーバーレイはベースと**同じ26×28ドットのキャンバス・同じ原点(足元中心)・同じ拡縮**で描くので必ずピクセル整合する。

## マスコット座標マップ（stand・キャンバス26×28、1ドット=3px）

```
   列(X): 4 . . . 8 . . .12 . . .16 . . .20 21
row 6                                            ← 被り物はここまで上に出してOK(角・帽子の先)
row 7
row 8  ┌───頭のてっぺん(輪郭は2つの山)───┐        ← 頭 上端
row 9  │                                 │
row10  │            頭                   │
row11  │                                 │        ← 目の1つ上
row12  │   ●●        ●●   │        ← 目(X9,10 と X15,16)。基本は隠さない
row13  │                                 │        ← 頬/口元
row14  ├────────── 胴 上端 ──────────┤        ← 着るものはここから
row15  │              胴                  │
row16  │                                 │
row17  │              胴                  │
row18  │                                 │
row19  │              胴                  │
row20  │                                 │
row21  └────────── 胴 下端 ──────────┘
row22   足  足  足                              ← 足元(stand)。原点は足元中心
```

- 体本体が占めるのは **X 4〜21 / Y 8〜22**。中心は X≒12〜13。
- **目**: row12 の X9,10（左目）と X15,16（右目）。**被り物は基本この2ドットを避ける**。
  ただし **サングラス・眼帯など「顔の一部を隠す」装備は目にかけてOK**。
- **被り物(head)**の主戦場: row 6〜13（頭の上〜目の高さ）。
- **着るもの(body)**の主戦場: row 14〜21（胴）。肩当てなどは row13 まで上げてOK。

## 定義フォーマット（JS データ）

```js
// 1パーツ = キャンバス上の絶対座標に置くドットグリッド
// y,x = グリッド左上のドット座標 / pal = 文字→色 / rows = 文字絵('.'=透過してベースを見せる)
{ y:6, x:3, pal:{ K:'#1a1a22', b:'#2b3a67', g:'#e8c24a' },
  rows:[
    "....gg....",   // 各文字 = pal のキー。'.' はスキップ(ベースのマスコットが見える)
    "...KbbK...",
    ...
  ] }

// 1スキン = 被り物 + 着るもの
{ id:'japan', n:'侍', head:{...}, body:{...} }
```

描画順: **body → head**(頭が体より前)。両方 `'.'` の所はベースのマスコットがそのまま見える＝顔・素肌・体色が残る。
色は装備側で固定（テーマ配色）。ベースの体色はオーバーレイで隠れていない部分に残る。

## 記入例①: 侍(japan) — 兜 + 胴丸

```js
japan: {
  id:'japan', n:'侍',
  // 兜: 紺のドーム(目の上まで) + 金の前立(三日月) + しころ(首回り)
  head: { y:6, x:3, pal:{K:'#111',b:'#33406b',s:'#232c4d',g:'#e8c24a'},
    rows:[
      "....gg....",     // 前立(金) 上端
      "...KggK...",
      "..KbbbbK..",     // 兜てっぺん
      ".KbbbbbbK.",
      ".KbsbbsbK.",     // 兜の縁
      "KbbbbbbbbK",
      "Ks......sK",     // ← 目の高さ(row12)。中央は空けて顔を見せる。両端はしころ
    ] },
  // 胴丸: 紺の甲冑 + 威毛(縅)の横ライン + 金の縁
  body: { y:14, x:4, pal:{K:'#111',b:'#33406b',s:'#232c4d',g:'#e8c24a'},
    rows:[
      "gKbbbbbbKg",     // 肩当て(金縁)
      "KbsbsbsbK.",
      "KbbbbbbbK.",
      "KbsbsbsbK.",
      "KbbbbbbbK.",
      ".KbbbbbK..",     // 裾すぼまり
      "..gK..Kg..",
    ] },
}
```

## 記入例②: 海賊(pirate) — 三角帽(ドクロ) + 眼帯 + 赤コート

```js
pirate: {
  id:'pirate', n:'海賊',
  head: { y:6, x:2, pal:{K:'#111',h:'#2a2320',w:'#f4f1e6',r:'#b23b3b'},
    rows:[
      "..hhhhhhhh..",   // 三角帽 上
      ".hhhhhhhhhh.",
      "hhhhwwhhhhhh",   // 中央にドクロ(白)
      "KKKKKKKKKKKK",   // 帽子の縁(黒)
      "......Kww...",   // ← 右目に眼帯(顔の一部を隠すのはOK) + ストラップ
    ] },
  body: { y:14, x:4, pal:{K:'#111',r:'#b23b3b',d:'#7d2727',y:'#e8c24a'},
    rows:[
      "KrrrrrrrrK",     // 赤コート肩
      "rrdKKdrr..",     // 前合わせ
      "rrrrrrrr..",
      "rryKKyrr..",     // ベルト(金バックル)
      "rrrrrrrr..",
      ".rrrrrr...",
      "..K..K....",
    ] },
}
```

## 記入例③: サイバー(tokyo) — ネオンバイザー(目を隠す) + 黒ジャケット

```js
tokyo: {
  id:'tokyo', n:'サイバー',
  head: { y:9, x:4, pal:{K:'#0a0a0f',c:'#28e6ff',p:'#ff2fa0'},

    rows:[
      "KdddddddK.",
      "dcdddddcd.",     // 襟のネオン(シアン)ライン
      "dddddddd..",
      "dcccccccd.",     // 胸のネオン
      "dddddddd..",
      ".dddddd...",
      "..d..d....",
    ] },
}
```
