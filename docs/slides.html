Claude Factory

今日の働きが、工場になる。

起動中の Claude Code が工場で働く仲間になる。実測した労働量で製品ができ、図鑑が埋まっていく。「使え」と言わずに AI 活用が続く形にした。

2026-08-05 ・ Built with Claude Code

01 — なぜ作ったか

働きは、ターミナルの中で消える

Claude Code はテレメトリで、ツール実行も差分もコミットも全部出している。データはもう取れている。なのに、それが本人に返ってくることはない。

いま

1日みっちり Claude Code で作業しても、残るのはコミット履歴だけ。
何をどれだけやったかは、閉じた瞬間に消える。積み上がっている感覚がないから、忙しくなれば手が止まる。

→
やりたかったこと

同じデータを、目に見えて増えるものに変える。
働いた分だけ工場が育ち、図鑑が埋まる。閉じても残るものにする。

出発点は「可視化」ではなく、働いた実感が残らないことだった。
02 — 課題

配るのは簡単。
続けてもらうのが難しい。

社内で AI 活用を推進する立場から見ると、詰まっているのはこの3つ。

01
定着しない「便利だから使って」で始まった活用は、忙しくなると最初に落ちる。使った分が何にも積み上がらないから、続ける理由が本人の中に残らない
02
使い方が見えないSkill を書く人、サブエージェントに任せる人、プロンプトだけで進める人。差は出ているはずなのに、それを見る手段が標準には無い
03
雑に測ると壊れる活動量を1つの数字にまとめて人を並べると、その数字を稼ぐ行動が強化される。狙いと正反対の順位ができあがる
要るのは 続けさせる仕組み と 測る仕組み。ただし同じ数字を両方に使ってはいけない。
03 — だから、こう決めた

ダッシュボードではなく、ゲームにした

3つの判断で、いまの形になっている。

  • 報酬を本人の側に置く。「見える化」だけでは続かない。働いた分が製品と図鑑になって残るから、自分のために開く
  • 退屈にしない。管理ツールは、退屈だと開かれなくなって終わる。ドット絵の工場は飾りではなく、習慣として続けさせるための機能
  • 同じテレメトリを二度使う。本人向けは「活動量」、組織向けは「使い方の多軸」。1つの数字に混ぜないことで、両方を壊さずに成立させる
測るために作ったのではない。続けてもらうために作ったものが、副産物として「誰がどう使えているか」を出す。順番を逆にすると、ただの監視ツールになって使われなくなる。
04 — Solution

働いた量を、
工場の生産に変える

働くと、工場が動くbusy のセッションは手を動かし、idle は 💤 で眠る。別のディレクトリで claude を叩けば新しい仲間が出勤してくる
数字は3つだけ出す今日の労働量(WP) / 今日の製造数 / 今日の売上。開いて3秒で「今日どれだけやったか」が分かる
採光は実時刻に連動朝・夕・夜で窓の外と照明が変わる。置きっぱなしにしても景色が動く
localhost:4321OTLP ● 5s
05 — ゲームシステム / 全体の流れ

働く → 作る → 集める → 広げる

⌨️働くツール実行・差分・コミット
→
⚡WPが溜まる重み付けして実測で加算
→
🏭製造機で作る素材の組合せで中身が決まる
→
📖図鑑に集める初回は NEW。埋めるのがゴール
→
🏪売って広げる製造機・装飾・背景・スキン
必要WPはマス数で決まる1製品 ＝ マス数 × 2,000WP。2マス機なら4,000WPで1個できる
原材料は3ジャンル🍳食品 / ⚙️機械 / 🧺生活品。ジャンルごとに作れる物の系統が違う
製品にはレア度があるN / R / SR / SSR / UR。上のレアほど売価が高い
止めている機械にはWPが入らない。稼いだWPは台数で按分せず、稼働中の全機械にそれぞれ同額を加算する。動かす台数を増やすほど並行して作れるので、💰を製造機に回す判断が効いてくる。
06 — ゲームシステム / 製造の仕組み

製造機は 2〜5マス。1マス＝素材1つ

マスに原材料をセットして動かすと、必要WPに達した時点の「入っている素材の集合」で何ができるかが決まる。順不同で、同じ素材の重複は1つと数える。

マス数を増やす＝作れる物が増える入れられる素材が増え、組合せの幅が広がる。大きい機械はショップで買う
必要WPも比例して増える大きい機械は当たりが太いぶん、1個できるまでに時間がかかる
レシピに無い組合せは 🪨 謎のカタマリ失敗しても記録は残る。総当たりではなく見当をつけて試す遊びになる
超過WPは次に繰り越す素材を入れ替えても製造は止まらず、溜めたWPもリセットされない
同じ組合せから複数の製品レア度の重みで引き分けるので、同じ組合せを何度も試して上位レアを狙える
できた瞬間に 💰 が入るレア度別の売価が加算される。図鑑には初回だけ NEW が付く
07 — ゲームシステム / 探す楽しみ

組合せは
教えない

  • 原材料は見せて、できる物は隠す。レシピ一覧はシルエットと ??? のまま並ぶ
  • 作れる物の予告も出さない。筐体の上に出るのは稼働状態と進捗だけ
  • 当てると図鑑が埋まる。一度作れば絵と名前が開いて、以降はレシピとして残る
  • これが継続の燃料になる。「あと1つ埋めたい」が、明日も開く理由になる
🧾 製造レシピ — 未発見はシルエット
08 — ゲームシステム / ショップ

稼いだ 💰 で、
工場を育てる

売上の使いどころが4種類ある。生産力にも、見た目にも振れる。

  • 製造機。2〜5マス。台数を増やすか、マス数を増やすか
  • 装飾。テーマごとの家具や名物を買って、床に好きに並べる
  • 背景。部屋ごと着せ替え。買えばいつでも切り替えられる
  • スキン。エージェントの被り物。プロジェクト単位で選べる
🏪 ショップ — 製造機 / 装飾 / 背景 / スキン
09 — 見た目の報酬

工場を、まるごと着替える

テーマは和風・海底・幽霊屋敷・宇宙ステーションなど、系統の違うものを取りそろえている。製造機の見た目は部屋テーマに自動で追従するので、買い替えずにテーマだけ変えれば工場ごと着替わる。

10 — マネジメントに効く

チームの活用量が、
軸ごとに見える

同じテレメトリから、AI活用を推進する側が知りたいことがそのまま出る。

  • 誰が使いこなしているか。Skill・Agent・自作Agent・委譲率で、上級者が浮かび上がる
  • 使っていない人が分かる。稼働日数だけで足りる。順位は要らない
  • 1on1の材料になる。「普段どう使っているか」を聞く入口ができる
  • 成果と併せて見られる。PR・コミット・変更行と、少ない試行で到達できているかの効率
🏆 リーダーボード — 日 / 週 / 月 / 年
11 — 測り方の設計

ただし、1つの数字で人を並べない

10日ぶんの実測。ゲーム用WPの構成比はこうなっていた。

Bash43.2%
Edit8.7%
Skill1.2%
Agent0.9%
評価したい Skill と Agent は、合計2%しかない。単一の合計値で並べると、Skill も Agent も使わず Bash を大量に叩く人が1位になる。だから指標を2つに分けた。
ゲーム用WP活動量。製造の燃料にだけ使い、人と人の比較には使わない
業務スコアカード生カウントを軸ごとに並べる。合計値は作らない
効率には最低成果フィルタPR1件かつ100行以上。満たさなければランク外
順位は査定ではなく会話の起点下位の人が上位の人に聞きに行くための表
