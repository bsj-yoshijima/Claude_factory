Claude Factory

今日の働きが、工場になる。

起動中の Claude Code が工場で働く仲間になる。実測した労働量で製品ができ、図鑑が埋まっていく。「使え」と言わずに AI 活用が続く形にした。

2026-08-05 ・ Built with Claude Code

01 — 課題

配るのは簡単。
続けてもらうのが難しい。

ツールは配れる。けれど使い続けてもらうことと、使えているかを測ることには手段が無い。

01
定着しない「便利だから使って」で始まった活用は、忙しくなると最初に落ちる。使った分が何にも積み上がらないから、続ける理由が本人の中に残らない
02
使い方が見えないSkill を書く人、サブエージェントに任せる人、プロンプトだけで進める人。差は出ているはずなのに、それを見る手段が標準には無い
03
雑に測ると壊れる活動量を1つの数字にまとめて人を並べると、その数字を稼ぐ行動が強化される。狙いと正反対の順位ができあがる
要るのは 続けさせる仕組み と 測る仕組み。ただし同じ数字を両方に使ってはいけない。
02 — Solution

働いた量を、
工場の生産に変える

働くと、工場が動くbusy のセッションは手を動かし、idle は 💤 で眠る。別のディレクトリで claude を叩けば新しい仲間が出勤してくる
報酬をゲームの側に置く実測した労働量(WP)がそのまま製造の燃料になる。開くたびに何かが進んでいる
眺めたくなる見た目にする退屈な管理画面は開かれなくなって終わる。ドット絵は飾りではなく、習慣として続けさせるための設計
localhost:4321OTLP ● 5s

04 — 探す楽しみ

組合せは
教えない

  • 原材料は見せて、できる物は隠す。レシピ一覧はシルエットと ??? のまま
  • 外れると 🪨 謎のカタマリ。だから「当てにいく」動機が生まれる
  • ジャンルを跨ぐと隠し当たり。特定の組合せだけ ✨シークレット（👽エイリアンなど）が出る
  • 同じ組合せから複数の製品。レア度の重みで引き分けるので、上位レアを狙って何度も試せる
🧾 製造レシピ — 未発見はシルエット
05 — 稼いだ 💰 の使いどころ

工場を、32テーマに着替える

部屋テーマ32種・製造機スプライト128枚（32テーマ×4サイズ）・プロップ290種。製造機の見た目は部屋テーマに自動で追従する。
採光は実時刻(JST)に合わせて朝・夕・夜と連続的に移ろう。

06 — マネジメントに効く

チームの活用量が、
軸ごとに見える

同じテレメトリから、AI活用を推進する側が知りたいことがそのまま出る。

  • 誰が使いこなしているか。Skill・Agent・自作Agent・委譲率で、上級者が浮かび上がる
  • 使っていない人が分かる。稼働日数だけで足りる。順位は要らない
  • 1on1の材料になる。「普段どう使っているか」を聞く入口ができる
  • 成果と併せて見られる。PR・コミット・変更行と、少ない試行で到達できているかの効率
🏆 リーダーボード — 日 / 週 / 月 / 年
07 — 測り方の設計

ただし、1つの数字で人を並べない

10日ぶんの実測。ゲーム用WPの構成比はこうなっていた。

Bash43.2%
Edit8.7%
Skill1.2%
Agent0.9%
評価したい Skill と Agent は、合計2%しかない。単一の合計値で並べると、Skill も Agent も使わず Bash を大量に叩く人が1位になる。だから指標を2つに分けた。
ゲーム用WP活動量。製造の燃料にだけ使い、人と人の比較には使わない
業務スコアカード生カウントを10軸で並べる。合計値は作らない
効率には最低成果フィルタPR1件かつ100行以上。満たさなければランク外
順位は査定ではなく会話の起点下位の人が上位の人に聞きに行くための表
